# Overview

The Knowledge Graph Epic transforms the Intermediate Representation (IR) generated by the Static Analysis Engine into a connected, queryable, and technology-agnostic model of the software system.

The Knowledge Graph becomes the single source of truth for every downstream capability in DevLens.

Rather than analyzing files, future modules consume relationships between software concepts.

This Epic establishes DevLens' core competitive advantage.

---

# Objectives

- Transform the Intermediate Representation into a graph model.
- Model software as interconnected nodes and relationships.
- Support incremental graph updates.
- Enable graph queries.
- Provide a stable API for downstream consumers.
- Decouple the rest of the platform from source code and ASTs.

---

# Scope

## Included

### Graph Construction

- Build graph from the Intermediate Representation.
- Create nodes.
- Create relationships.
- Validate graph consistency.
- Support incremental updates.

### Node Types

The graph should represent software concepts including:

- Project
- Workspace
- Repository
- Package
- Module
- Controller
- Service
- Repository Class
- Entity
- Aggregate
- Value Object
- DTO
- Interface
- Enum
- Event
- Command
- Query
- API Endpoint
- Middleware
- Guard
- Pipe
- External Dependency

The model must remain extensible.

### Relationship Types

Examples include:

- BELONGS_TO
- IMPLEMENTS
- EXTENDS
- IMPORTS
- DEPENDS_ON
- EXPOSES
- USES
- CALLS
- RETURNS
- ACCEPTS
- EMITS
- HANDLES
- REFERENCES
- OWNS

Relationship types should describe software semantics rather than language syntax.

### Graph Query API

Support queries such as:

- Dependencies
- Dependents
- Module hierarchy
- Service relationships
- API ownership
- Event flows
- Domain boundaries
- Impact analysis

### Incremental Updates

The graph should update only affected nodes after repository changes.

Complete graph rebuilds should be avoided whenever possible.

### Graph Versioning

Support snapshots of the graph.

Future features will use these snapshots for architecture comparison and historical analysis.

---

# Out of Scope

The following capabilities are intentionally excluded:

- Graph visualization.
- AI interactions.
- Documentation generation.
- Semantic search.
- Architecture scoring.
- User annotations.
- Collaboration features.

This Epic focuses exclusively on building and exposing the graph.
